## ❓ FAQ - Foire aux Questions

### 📚 Questions Générales

**Q: Quelle est la stack technique de CESIZen ?**
A: Flutter/Dart, Firebase (Auth, Firestore, Storage), Provider/GetX pour state management, SQLite pour cache local.

**Q: L'app supporte-t-elle le mode offline ?**
A: Oui, stratégie offline-first avec synchronisation automatique à la reconnexion.

**Q: Quelles sont les plateformes supportées ?**
A: iOS (12.0+), Android (API 21+). Web en développement.

### 🔧 Questions Développement

**Q: Comment ajouter un nouvel écran ?**
A: 1. Créer la classe screen dans `lib/features/feature_name/presentation/screens/`
2. Ajouter le ViewModel dans `presentation/viewmodels/`
3. Configurer la route dans `lib/app/router.dart`
4. Ajouter aux providers dans `lib/core/di/injector.dart`

**Q: Comment gérer les erreurs réseau ?**
A: Utiliser les interceptors Dio dans `ApiClient`. Voir [13-exemples-integration.md](13-exemples-integration.md) section gestion d'erreurs.

**Q: Comment ajouter une nouvelle API ?**
A: 1. Créer le service dans `lib/core/services/api/`
2. Définir les modèles dans `lib/core/models/`
3. Ajouter aux repositories dans `lib/core/repositories/`
4. Injecter dans les ViewModels

### 🎨 Questions UI/UX

**Q: Comment maintenir la cohérence UI ?**
A: Utiliser le `ThemeData` défini dans `lib/core/theme/app_theme.dart` et les composants réutilisables du dossier `lib/shared/widgets/`.

**Q: Comment gérer le responsive design ?**
A: Utiliser `MediaQuery` et `LayoutBuilder`. Voir exemples dans [06-authentification-ui.md](06-authentification-ui.md).

**Q: Comment implémenter l'accessibilité ?**
A: Ajouter `Semantics` widgets, labels descriptifs, et tester avec TalkBack/VoiceOver.

### 🚀 Questions Déploiement

**Q: Comment faire un build release ?**
A: `flutter build appbundle --release` pour Android, `flutter build ios --release` pour iOS. Détails dans [14-deployment.md](14-deployment.md).

**Q: Comment configurer Firebase ?**
A: 1. Créer projet Firebase
2. Ajouter `google-services.json` (Android) et `GoogleService-Info.plist` (iOS)
3. Initialiser dans `main.dart`

**Q: Comment gérer les versions ?**
A: Incrémenter `version` dans `pubspec.yaml`, `versionCode`/`versionName` dans `build.gradle` et Xcode.

### 🐛 Questions Debugging

**Q: L'app crash au démarrage ?**
A: Vérifier les logs: `flutter logs`. Vérifier configuration Firebase et permissions.

**Q: Les API ne marchent pas ?**
A: Vérifier connectivité, tokens JWT expirés, et configuration Dio interceptors.

**Q: Problème de performance ?**
A: Utiliser Flutter DevTools pour profiler. Vérifier lazy loading et cache.

### 📊 Questions Métriques

**Q: Comment tracker les événements utilisateur ?**
A: Utiliser `FirebaseAnalytics` dans les services. Voir exemples dans [14-deployment.md](14-deployment.md).

**Q: Comment monitorer les crashes ?**
A: Firebase Crashlytics automatiquement configuré. Rapports dans console Firebase.

**Q: Quelles métriques suivre ?**
A: Sessions, durée, rétention, taux de conversion, satisfaction utilisateur.
